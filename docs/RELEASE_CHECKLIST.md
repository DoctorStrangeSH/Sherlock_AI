# Sherlock AI 1.0 — Release Checklist

## Перед сборкой
- [ ] PR #1 прошёл ревью; целевая ветка и commit SHA зафиксированы.
- [ ] Все CI jobs зелёные на том же commit SHA, который идёт в релиз.
- [ ] Полный набор unit-тестов проходит.
- [ ] Нет blocker/critical открытых дефектов.
- [ ] В репозитории и release artifacts нет .env, *.session, токенов, API hash, баз пользователя или логов с секретами.
- [ ] Скомпрометированная старая Telegram-сессия отозвана владельцем; новые credentials не публиковались.

## Windows package
- [ ] Windows build workflow завершился успешно.
- [ ] EXE smoke test завершился с кодом 0.
- [ ] Приложение запускается на чистой Windows без Python.
- [ ] Первый запуск, Ollama unavailable, отсутствующая модель и ошибки доступа объясняются понятным языком.
- [ ] UI не зависает во время генерации.
- [ ] Закрытие/повторный запуск не повреждает данные.

## Сквозные сценарии
- [ ] Чат: модель выбрана → запрос отправлен → потоковый ответ получен.
- [ ] История: диалог сохранён → приложение перезапущено → диалог открыт.
- [ ] Задачи: создать → изменить → завершить → удалить с подтверждением.
- [ ] Заметки: создать → изменить → найти/просмотреть → удалить.
- [ ] Память: сохранить явно → увидеть использование → просмотреть → удалить.
- [ ] Файлы: выбрать разрешённую папку → найти файл → открыть предпросмотр → обработать неподдерживаемый файл.
- [ ] Backup: создать копию → восстановить → проверить данные.

## Telegram — выбрать один вариант
- [ ] Включён: свежая сессия авторизована; разрешённый контакт проверен; черновик создан/отредактирован/отменён; отправка произошла только после подтверждения.
- [ ] Выключен в релизе 1.0: интеграция не запускается автоматически, UI не обещает недоступную функцию, документация объясняет, что Telegram появится в обновлении.
