# Sherlock AI

Личный Telegram-секретарь на Python/Telethon с необязательным **бесплатным локальным ИИ** через [Ollama](https://ollama.com/). Это пока основа ассистента, не автономный оператор компьютера.

## 🔴 Обязательно перед запуском

В первоначальном `config.py` были опубликованы Telegram API hash и **StringSession**. **Немедленно завершите скомпрометированную Telegram-сессию** через Telegram → Настройки → Устройства (или Активные сеансы); создайте новую сессию. Перевыпустите API credentials, если возможно. Удаление секретов из нового коммита **не удаляет их из Git-истории**. Не публикуйте новый SESSION_STRING.

## Запуск

1. Python 3.11+, `pip install -r requirements.txt`.
2. Задайте переменные из `.env.example` в окружении (сам файл `.env` автоматически не читается). Нужен новый `TELEGRAM_SESSION_STRING`, полученный локально безопасным способом.
3. `python secretary.py`. Для работы нужны доступ Telegram API и группа с темами.
4. Проверьте локальную установку:
   - `python doctor.py --offline` — конфигурация, зависимости, SQLite.
   - `python doctor.py` — то же плюс доступность локальной Ollama и модели.

   Диагностика не печатает значения секретов, не подключается к Telegram и не проверяет действительность Telegram-сессии. Запускать её безопасно до `secretary.py`.
5. Необязательно: установите Ollama, выполните `ollama pull qwen3:8b`, запустите Ollama локально. В Telegram откройте **Избранное** (Saved Messages) своего аккаунта и отправьте `.ask Привет!`. Личные команды ИИ работают только там, чтобы заметки не появлялись в чужих чатах.

Команды `.menu`, `.status`, `.mode`, `.online`, `.offline`, `.remind`, `.stats`, `.filter`, `.addwhite`, `.addblack`, `.ask` работают **только для исходящих сообщений** Telegram-аккаунта, на котором работает Telethon. Сообщения других людей их не активируют. Изменения статуса и режима сохраняются в SQLite.

Ограничения: Ollama исполняется на вашем оборудовании; без интернета для генерации после скачивания модели, без платы за API, но требует оперативной памяти и вычислительных ресурсов. Сервис должен иметь доступ к Ollama URL: в Docker `127.0.0.1` означает сам контейнер, поэтому нужен отдельный сетевой адрес. Память диалога работает локально в SQLite: только запросы владельца через `.ask` и ответы модели. Для каждого владельца хранится не более 100 последних реплик; к модели передаются не более 12 последних реплик плюс новый вопрос. `.memory` показывает состояние истории, `.forget` удаляет её целиком. Долговременные заметки сохраняются **только явно** через `.remember текст`, просматриваются через `.memories` и удаляются через `.forgetfact номер` (или полностью: `.forgetallfacts CONFIRM`). Максимум 50 заметок по 500 символов на владельца. Для характера используйте `.tone warm`, `.tone concise` или `.tone professional` (только в «Избранном»). `.forget` не удаляет заметки, а `.forgetallfacts` не удаляет историю диалога. История входящих сообщений третьих лиц в модель не передаётся. База SQLite не шифруется: защищайте файлы и резервные копии на своём компьютере. Задачи: `.taskadd текст`, `.tasks`, `.taskdone номер`, `.taskdelete номер` в «Избранном». Открытые задачи доступны модели только как справочная информация при `.ask` (до 50 названий); модель **не помечает** задачи завершёнными сама. Доступ к файлам и действия в сторонних сервисах **ещё не реализованы**. Не давайте модели разрешение выполнять произвольный код.

## Windows-приложение Sherlock AI (первый прототип)

После установки Python 3.11+ и [Ollama](https://ollama.com/download/windows) загрузите модель. Для RTX 4060 Ti 8 ГБ можно начать с `ollama pull qwen3:8b`; Qwen 3.5 9B в Q4-квантовании имеет меньший запас видеопамяти. Запустите:

```powershell
python desktop_app.py
```

Откроется тёмное окно чата. `Ctrl+Enter` отправляет сообщение; можно выбрать тёплый, краткий или деловой стиль и очистить контекст. Ответ генерируется в фоновом потоке, интерфейс остаётся доступным. История сохраняется только в памяти процесса (не на диске). Первый ответ Ollama может занимать время на загрузку модели. **Это ранний прототип**: графический запуск под Windows ещё требует проверки пользователем, голос и управление компьютером не реализованы. Если Python не находит `tkinter`, установите стандартную сборку Python с Tcl/Tk.

## Быстрый тест без Telegram

После установки [Ollama](https://ollama.com/) и загрузки модели (`ollama pull qwen2.5:3b`) можно проверить живой диалог **без Telegram-ключей, Telegram-сессии и базы данных**:

```powershell
python chat_cli.py
```

Введите обычное сообщение и получите ответ локальной нейросети. `/clear` очищает контекст текущего сеанса, `/exit` выходит. Этот режим не сохраняет разговоры на диск; контекст хранится только до завершения процесса. Если Ollama не установлена или модель не запущена, программа объяснит причину.

## Настройка Telegram без копирования секретов в чат

**Сначала** отзови старую опубликованную сессию в Telegram → Настройки → Устройства и получи новые API credentials, если возможно. На своём ПК в папке репозитория выполни:

```powershell
python -m pip install -r requirements.txt
python telegram_setup.py
python run_local.py doctor.py --offline
python run_local.py telegram_check.py
```

`telegram_setup.py` попросит API ID, API hash, затем предложит сетевой режим IPv6 (по умолчанию да), номер, код Telegram и при необходимости пароль 2FA. Если IPv4-маршрут к Telegram недоступен, а IPv6 работает, оставь выбор IPv6 по умолчанию. Настройка `TELEGRAM_USE_IPV6=true` сохраняется локально и применяется также в `telegram_check.py` и `secretary.py`. Telethon поддерживает IPv6 через `use_ipv6=True`. Он создаст новую **локальную** сессию в файле `.env`; StringSession нигде не показывается и не отправляется в Git. Файл хранит секреты **в открытом виде**: не пересылай его, защити Windows-аккаунт и не делай общедоступных резервных копий. При наличии `.env` настройка отказывается перезаписывать его. `telegram_check.py` только проверяет действительность сессии и ID владельца — **не отправляет** никаких сообщений.

ID группы с темами потребуется для старого механизма уведомлений (обычно отрицательный `-100...`). Если группы пока нет, при настройке оставь поле пустым, затем вручную укажи `TELEGRAM_GROUP_ID` в `.env` перед запуском `secretary.py`. Запуск с файла локальных настроек: `python run_local.py secretary.py`. Не запускай `secretary.py`, пока проверка аккаунта не прошла. Ни одна из этих команд не проверялась на твоём Windows и живом Telegram — жду результат безопасной проверки.

## Windows (PowerShell)

В открытой консоли PowerShell задавайте необходимые переменные через `$env:TELEGRAM_API_ID = '...'` и аналогично для остальных имён из `.env.example`. Не пересылайте строку сессии и не добавляйте её в скрипты или Git. Значения, установленные через `$env:`, действуют только в текущем окне PowerShell.

После настройки:

```powershell
python -m pip install -r requirements.txt
python doctor.py --offline
python doctor.py
python secretary.py
```

Для обращения к модели используется Telegram → «Избранное» и команда `.ask`.

## Черновики ответов в личном Telegram

Этот режим выключен по умолчанию. Сначала завершите скомпрометированную Telegram-сессию (см. предупреждение в начале README), затем запустите `secretary.py` со свежими секретами. Чтобы разрешить контакт без сообщений посторонним, отправьте в **Избранном** `.draftcontacts`, затем `.draftallow ID` для известного собеседника. Команда `.draftdeny ID` немедленно отключает его и удаляет ожидающие черновики и оперативный контекст. Контакты появляются в списке после получения личного сообщения (список ограничен 20 контактами). Старая `.addwhite` по-прежнему существует, но использовать её в личных чатах не требуется. В **Избранном** отправьте `.drafts on`. После этого новые **текстовые личные** сообщения от разрешённых контактов передаются в локальную Ollama; предложение приходит только в ваше **Избранное**. Предложение **не отправляется собеседнику автоматически**: прочитайте текст, затем в «Избранном» отправьте `.senddraft НОМЕР` для точной отправки предложенного текста либо `.canceldraft НОМЕР` для отмены. Для отдельного стиля собеседника в «Избранном» отправьте `.drafttone ID_КОНТАКТА warm`, `.drafttone ID_КОНТАКТА concise` или `.drafttone ID_КОНТАКТА professional`. ID показывается рядом с новым черновиком. Настройку можно менять только для контакта из белого списка, она сохраняется в локальной SQLite. Для изменения черновика прямо в «Избранном» отправьте `.editdraft НОМЕР новый текст`; `.showdraft НОМЕР` покажет текущий вариант перед отправкой. Редактирование не меняет адресата или время истечения. Если удобнее, можно скопировать текст и отправить его вручную. Черновик одноразовый, хранится в оперативной памяти процесса до 30 минут и пропадает после перезапуска. При ошибке доставки черновик погашается, чтобы повторное подтверждение не создало дубль. Для остановки: `.drafts off` — также удаляет текущие ожидающие черновики.

Поддерживаются только личные чаты из белого списка; группы, каналы, вложения, неизвестные контакты и длинные сообщения исключены. Включение функции является согласием на локальную обработку текста выбранных контактов. Полная история Telegram не загружается. Пока режим включён, для каждого разрешённого контакта в оперативной памяти собираются до 6 последних коротких текстовых реплик (его и владельца); в запрос модели передаются до 4 предыдущих фрагментов и новое сообщение. Контексты разных контактов изолированы, не сохраняются на диск, очищаются при `.drafts off` и перезапуске. До включения режима переписка не анализируется; вложения не читаются. Режим работает, лишь пока запущен `secretary.py`, Telegram доступен и Ollama отвечает. Старые автоматические ответы при статусе «оффлайн» отключены, чтобы система не писала людям без подтверждения. Кнопки подтверждения, редактирование внутри интерфейса и полноценный контекст диалогов добавим после тестирования этого этапа.

## Примеры собственного стиля (только по желанию)

Sherlock AI не обучается на всей переписке автоматически. Чтобы дать ассистенту образцы твоей манеры общения, в **Избранном** введи `.styleadd Привет! Давай чуть позже созвонимся :)`. Можно сохранить до пяти примеров длиной 10–240 символов каждый. Просмотр: `.stylelist`, удаление одного: `.styledelete 1`, удаление всех: `.styleclear CONFIRM`. В локальный запрос модели попадают максимум четыре коротких примера как ориентир по стилю, а не как факты, обязательства или команды. Примеры сохраняются в локальной базе SQLite **без шифрования**: не добавляй пароли, адреса или чувствительные данные. Они удаляются по твоей явной команде, а не при `.drafts off`.

## Безопасная проверка цепочки ответов без Telegram

Перед настройкой сессии можно проверить реальную логику черновиков на **вымышленных** сообщениях:

```powershell
python simulate_reply_flow.py
```

Скрипт проверяет изоляцию контактов, формирование контекста, создание черновика, редактирование, запрет отправки без разрешения и одноразовое подтверждение. Он **не подключается** к Telegram, не вызывает Ollama и **не отправляет** сообщения реальным людям. Это интеграционная симуляция, а не доказательство работы Telethon и GPU на Windows. Для живого теста потребуется отдельно настроить и защитить Telegram-сессию. Если `curl.exe -4 -I --connect-timeout 10 https://api.telegram.org` завершается тайм-аутом, а аналогичная команда с `-6` получает HTTP-ответ, при настройке выбери IPv6. Если IPv6 тоже недоступен, используй только сетевой маршрут или прокси, разрешённый владельцем корпоративной сети.

## Локальные задачи и заметки без Telegram

Для первого знакомства с Sherlock AI **не нужна авторизация Telegram**. Открой окно чата:

```powershell
python desktop_app.py
```

Нажми **«Задачи и заметки»** внизу окна. Можно добавлять задачи, отмечать их выполненными и хранить заметки. Для проверки без Ollama и без чата также доступна отдельная команда:

```powershell
python offline_workspace_app.py
```

Данные автоматически сохраняются в `%LOCALAPPDATA%\\SherlockAI\\workspace.sqlite3` на Windows. Они не синхронизируются с Telegram и не отправляются в облако; SQLite-файл не зашифрован, поэтому защищай учётную запись Windows и резервные копии. Удаление выбранной записи требует подтверждения. Диалог с ИИ продолжает требовать локальную Ollama, но окно задач и заметок работает без неё.

Для диагностики личного Telegram используй `python telegram_connection_probe.py` — программа не запрашивает код и не сохраняет сессию. В `telegram_setup.py` есть отдельный выбор IPv6 или MTProto-прокси; код входа запрашивай только когда готов пройти авторизацию.
