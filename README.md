# Sherlock AI

Личный Telegram-секретарь на Python/Telethon с необязательным **бесплатным локальным ИИ** через [Ollama](https://ollama.com/). Это пока основа ассистента, не автономный оператор компьютера.

## 🔴 Обязательно перед запуском

В первоначальном `config.py` были опубликованы Telegram API hash и **StringSession**. **Немедленно завершите скомпрометированную Telegram-сессию** через Telegram → Настройки → Устройства (или Активные сеансы); создайте новую сессию. Перевыпустите API credentials, если возможно. Удаление секретов из нового коммита **не удаляет их из Git-истории**. Не публикуйте новый SESSION_STRING.

## Запуск

1. Python 3.11+, `pip install -r requirements.txt`.
2. Задайте переменные из `.env.example` в окружении (сам файл `.env` автоматически не читается). Нужен новый `TELEGRAM_SESSION_STRING`, полученный локально безопасным способом.
3. `python secretary.py`. Для работы нужны доступ Telegram API и группа с темами.
4. Проверьте локальную установку:
   - `python doctor.py --offline` — конфигурация, зависимости, SQLite.
   - `python doctor.py` — то же плюс доступность локальной Ollama и модели.

   Диагностика не печатает значения секретов, не подключается к Telegram и не проверяет действительность Telegram-сессии. Запускать её безопасно до `secretary.py`.
5. Необязательно: установите Ollama, выполните `ollama pull qwen3:8b`, запустите Ollama локально. В Telegram откройте **Избранное** (Saved Messages) своего аккаунта и отправьте `.ask Привет!`. Личные команды ИИ работают только там, чтобы заметки не появлялись в чужих чатах.

Команды `.menu`, `.status`, `.mode`, `.online`, `.offline`, `.remind`, `.stats`, `.filter`, `.addwhite`, `.addblack`, `.ask` работают **только для исходящих сообщений** Telegram-аккаунта, на котором работает Telethon. Сообщения других людей их не активируют. Изменения статуса и режима сохраняются в SQLite.

Ограничения: Ollama исполняется на вашем оборудовании; без интернета для генерации после скачивания модели, без платы за API, но требует оперативной памяти и вычислительных ресурсов. Сервис должен иметь доступ к Ollama URL: в Docker `127.0.0.1` означает сам контейнер, поэтому нужен отдельный сетевой адрес. Память диалога работает локально в SQLite: только запросы владельца через `.ask` и ответы модели. Для каждого владельца хранится не более 100 последних реплик; к модели передаются не более 12 последних реплик плюс новый вопрос. `.memory` показывает состояние истории, `.forget` удаляет её целиком. Долговременные заметки сохраняются **только явно** через `.remember текст`, просматриваются через `.memories` и удаляются через `.forgetfact номер` (или полностью: `.forgetallfacts CONFIRM`). Максимум 50 заметок по 500 символов на владельца. Для характера используйте `.tone warm`, `.tone concise` или `.tone professional` (только в «Избранном»). `.forget` не удаляет заметки, а `.forgetallfacts` не удаляет историю диалога. История входящих сообщений третьих лиц в модель не передаётся. База SQLite не шифруется: защищайте файлы и резервные копии на своём компьютере. Задачи: `.taskadd текст`, `.tasks`, `.taskdone номер`, `.taskdelete номер` в «Избранном». Открытые задачи доступны модели только как справочная информация при `.ask` (до 50 названий); модель **не помечает** задачи завершёнными сама. Доступ к файлам и действия в сторонних сервисах **ещё не реализованы**. Не давайте модели разрешение выполнять произвольный код.

## Быстрый тест без Telegram

После установки [Ollama](https://ollama.com/) и загрузки модели (`ollama pull qwen2.5:3b`) можно проверить живой диалог **без Telegram-ключей, Telegram-сессии и базы данных**:

```powershell
python chat_cli.py
```

Введите обычное сообщение и получите ответ локальной нейросети. `/clear` очищает контекст текущего сеанса, `/exit` выходит. Этот режим не сохраняет разговоры на диск; контекст хранится только до завершения процесса. Если Ollama не установлена или модель не запущена, программа объяснит причину.

## Windows (PowerShell)

В открытой консоли PowerShell задавайте необходимые переменные через `$env:TELEGRAM_API_ID = '...'` и аналогично для остальных имён из `.env.example`. Не пересылайте строку сессии и не добавляйте её в скрипты или Git. Значения, установленные через `$env:`, действуют только в текущем окне PowerShell.

После настройки:

```powershell
python -m pip install -r requirements.txt
python doctor.py --offline
python doctor.py
python secretary.py
```

Для обращения к модели используется Telegram → «Избранное» и команда `.ask`.
