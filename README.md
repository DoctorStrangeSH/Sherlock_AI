# Sherlock AI

Персональный локальный ИИ-ассистент для Windows. Проект находится в разработке; текущая цель — ограниченный и проверяемый релиз **1.0.0**.

## Что уже есть в репозитории

- Desktop-интерфейс чата и отдельное локальное рабочее пространство.
- Подключение локальной модели через Ollama, потоковая генерация и выбор модели.
- Локальное хранение задач, заметок и пользовательской памяти.
- Поиск по выбранным локальным папкам, недавние файлы и предпросмотр поддерживаемых документов.
- Telegram-интеграция через Telethon/MTProto с настройкой подключения и черновиками ответов.
- Автоматические тесты и GitHub Actions для Python-проверок и Windows preview-сборки.

Наличие реализации в коде не означает, что каждый сценарий уже прошёл ручную проверку. Текущий статус и критерии готовности ведутся в [Roadmap](docs/ROADMAP.md).

## Быстрый запуск Windows

Требуется Python 3.11+ для запуска из исходников.

```powershell
python -m pip install -r requirements.txt
python desktop_app.py
```

Для диалога с моделью установите [Ollama](https://ollama.com/download/windows), загрузите подходящую вашей системе модель и убедитесь, что локальный сервис Ollama запущен.

Sherlock AI не требует обязательной авторизации Telegram для запуска desktop-интерфейса и локального рабочего пространства.

### Отдельные режимы

| Команда | Назначение |
|---|---|
| `python desktop_app.py` | Основное desktop-приложение |
| `python offline_workspace_app.py` | Рабочее пространство без чата с ИИ |
| `python chat_cli.py` | Минимальная CLI-проверка локального диалога |
| `python doctor.py --offline` | Проверка локальной конфигурации и зависимостей |
| `python doctor.py` | Дополнительно проверяет доступность Ollama |
| `python simulate_reply_flow.py` | Симуляция сценария черновика без Telegram и отправки сообщений |

## Telegram — дополнительная интеграция

Telegram не нужен для первого запуска desktop-приложения. Для настройки личного аккаунта используй локально `telegram_setup.py`, затем проверь сессию через `telegram_check.py`.

**Важно:** ранее в Git-истории проекта находились Telegram credentials и StringSession. Старую сессию необходимо отозвать в Telegram → Настройки → Устройства; API credentials по возможности перевыпустить. Не публикуй `.env`, session-файлы, коды входа, пароли или токены и не отправляй их в чаты.

Telegram-функции не должны отправлять сообщения без явного подтверждения пользователя. Живое подключение и отправка требуют отдельной ручной проверки владельцем.

## Разработка и проверки

Установка зависимостей:

```powershell
python -m pip install -r requirements.txt
```

Проверки:

```powershell
python -m compileall -q .
python -m unittest discover -s tests -v
```

Windows preview workflow дополнительно запускает тесты, проверяет GUI self-test, собирает PyInstaller package и выполняет smoke-test EXE. Успешная сборка preview не равна опубликованному стабильному установщику.

## Принципы проекта

1. Сначала надёжный релиз 1.0, затем новые функции.
2. Не удалять модуль, пока не доказано, что он не используется.
3. Не переписывать работающий код без воспроизводимой причины.
4. Секреты, локальные базы и пользовательские данные не коммитить.
5. Считать функцию готовой только после проверки её сценария.
